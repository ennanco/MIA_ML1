# Practical Teacher website publication

This directory contains a static English website for the ML1 MIA - Practical Teacher plugin.

## Before publication

- Review the Privacy and Terms sections in index.html. They are explicitly marked as drafts.
- Confirm the support mailbox handling, including retention and any institutional requirements. Add confirmed details before removing the draft labels.
- Confirm the plugin remains instructions-only and reads public notebooks; update the privacy text if tools or integrations change.
- Add the public plugin installation link only after publication and testing with an intended student account.

## GitHub Pages setup

After merging, open repository Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and /docs, then Save. Repository administration access may be required. Use the deployed URL shown by GitHub; the expected project URL is https://ennanco.github.io/MIA_ML1/.

This uses the course repository and does not require editing the research-profile repository.
